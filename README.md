# En bättre bild – showroom

3D-showroom för fotofirman En bättre bild. En enda sida (`index.html`) med Three.js, utan byggsteg.

- `index.html` – hela sajten: rummen, ljusbakningen, ljud och styrning
- `img/` – fotona som hänger på väggarna

## Publicering
Cloudflare Pages bygger direkt från `main`: inget byggkommando, utdatakatalog `/`.

## Lägga till ett foto (tills personalrummet finns)
Lägg bilden i `img/` och fyll i `src` och `title` för platsen i `PHOTOS` i `index.html`.
